## 主要修正

| 问题 | 修改与论文对应 |
|---|---|
| OES 后额外的字符串硬拦截导致过度拒答 | 主实验配置 `evidence_policy=paper`，按 §4.1 和 Algorithm 1 采用 OES 的语义结果。额外原文、坐标、别名检查保留为 `evidence_audit` 诊断，不能冒充另一个模型拒答决定。单独调用库类的历史 `strict` 模式仍可用于审计测试。 |
| 缺少显式输出单位的正常标量被误判；FinQA 金标尺度未知被当成基本货币单位 | 从题目、金标原始单位和唯一来源报告声明确定展示单位；不根据预测挑选乘数；已知币种/维度冲突仍在评分中判错。附录 F 不要求 `trace.output_meta`，缺少该附加字段按任务展示单位解释。 |
| 单位表达、表头、OCR 和别名格式不稳定 | 标准化千/百万/每股/数量单位等表示；识别跨列年份、日期和指数名称、分段和省略列引文；保留实际原文、列号与诊断。只做表示适配，不在 OES 中计算金融值。 |
| OQA 空计划、跨多个年份的向量目标、限定词丢失 | 强化非空标量子目标契约，支持论文 `(metric,C)` 的 JSON 二元组表示；展开明确枚举的年份；将额外 `metric_qualifier` 保留在指标名中，不静默丢弃“现金支付”等限制。空计划和 unknown 占位指标仍是技术错误，不能记为正确拒答。 |
| 复合时间限定被误拆成两个年份 | 仅拆分明确的独立年份枚举；“截至某日；一年内到期”等合取条件保持一个完整约束，不凭分号增加操作数。 |
| 普通数量乘单价、指数收益题误入企业财务公式 | 区分外层基本算术与 ROE 等具体派生财务指标；规范名称提示同时附定义，避免同名产品类别被误当成资产负债表概念。 |
| 年金等反解造成 SymPy 无限递归/卡死 | 先检查直接父证据；简单唯一反解快速处理，复杂代数求解放入有 3 秒期限的独立进程；保留失败原因。只使用图中父公式，仍限制为一跳、其他输入必须直接存在。 |
| 已知无效路径继续占用 API 队列 | 必需操作数缺失时结束该路径；按活跃消费者引用计数取消无人需要的未完成子树，保护其他路径共享的任务。已经完成的值仍缓存；被取消且尚未获得结果的工作如以后确实需要，可重新启动。没有删除可能有效的候选公式。 |
| 生成 Python 使用 `null`、普通字典方法、数学函数被无差别禁止 | 无绑定 JSON 常量只做语法适配；允许必要的安全字典/列表操作、数学函数；仍禁止 import、文件、网络、eval/exec、私有属性；数学未定义值传播为缺失，程序错误保留。 |
| 百分比与金额操作数混淆、变化率符号错误 | OQA 保留输入自身单位；OPE 明确输入归一化、输出尺度，变化率使用带符号基期 `(new-old)/old`，不任意取绝对值，不提前舍入。比例/百分比输出的币种及货币尺度由维度规则清除，原始程序 trace 保留，不修改数值。 |
| Verify 路径 ID 格式错误 | 单次审核的格式槽直接填入真实候选 ID，逐候选保留判断及理由，没有添加第二个 judge 或按深度选答案。 |
| 旧结果、代码与新指标混用 | 每轮独立快照、配置、身份校验、预测日志与报告。旧全量源码和结果未改动；全量入口读取用户暂停标记并拒绝继续。 |

## 公开文本未唯一规定的设置

附录 F 的五段提示词正文保持原样。论文未展开 `{format}` 和 `{example}`；当前格式槽与少量通用 OQA 示例明确记为本地实现，示例不取自验证题，不声称是作者未公开的示例。没有让模型看到金标、解题程序或反事实标签。

该接口通过独立格式探针接受了 JSON Schema、非空数组以及不含前后空白的指标名约束；仅对 OQA 启用。四字段、类型枚举和约束字段均来自论文输出结构，不增加模型调用或候选回答。形式约束不等于语义正确：模型仍产生了扩展的占位描述，当前会明确记为规划错误，而不是转换成“正确拒答”。相关探针保存在 `runs/gbfr_v3_validation/`，不计入 66 题成绩。

§5.1 规定按相同精度归一化比较，但没有唯一规定未指定精度时的默认位数。修复前固定两位，会把金标 `34.4%` 与正确的未舍入 `34.3936…%` 判错。当前 `reference_display` 约定为：问题明确精度优先，否则按金标展示的小数位同步舍入。选择只取决于题目/金标，完全不查看预测；不改变符号、数值或已知单位。报告同时保留固定两位小数的诊断分数，不能隐藏口径差异，也不声称作者确认了这一默认规则。

最新轮次在同一 `gpt-5.6-sol` 上显式设置 `reasoning_effort=high`。平台已接受此字段，但其内部实现不可独立核实；论文未公开对应推理预算，故这是记录在配置中的工程设置，不是声称找到作者超参数。

现有 FMKG 来自预先冻结的公开知识库重建，图谱与测试资产没有在这次修复中按验证答案改写。它仍不是作者未公开的最终专家图谱；小样本达到数值门槛也不能证明全量结果相同。
