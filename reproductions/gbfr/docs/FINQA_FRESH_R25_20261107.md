# FinQA总准确率审计、修复与全新10题验证

本轮只调用FinQA，TAT-QA没有API调用，全量保持暂停。10题均在代码修复后首次执行真实API；不换题、不删除失败、不改金标、不按正确率重试。

## 上一轮70%有什么问题

R24的分子分母没有算错：8道原始题中5道正确，2道不可回答题均正确拒答，Total=(5+2)/10=70%。按标签计误拒1/8；Abst.=2/2是不可回答子集召回，全部拒答的正确比例实际上是2/3。

精度规则会明显改变结果。同样的冻结预测按参考答案展示位数为70%，统一两位为40%；论文要求同一精度比较、举两位例子，但未明确默认精度如何选择。因此70%不能被直接宣称为与论文全量完全同口径，fixed2也不应被声称是论文唯一强制设置。R24是反复调试的同题集，样本比例、骨干和规模也与论文不同。

## 误拒原因与本轮修改

R24唯一“误拒”是MKTX：问题要求流通股outstanding，材料只有授权股authorized，官方程序却拿授权股数求比率。严格遵守来源约束时拒答有依据，不能为了过金标把两者当同义词。

另外确认并修复了可泛化的实现问题：

- OQA图名称提示会把普通change推荐成证券收盘价Net Change、term推荐成时长，或把equity investments片段推荐成股东权益。新增保守词边界及完整度过滤，保留完整金融多词指标和正常缩写；不修改图别名、原始请求或OQA响应。
- 评分器在目标单位全未知时曾抹去预测明确声明的货币/缩放单位，可能将同数字但不同量级误算正确；现标记单位未判定，保守不记为已验证正确，不丢弃题目。
- 目标量后的括号单位如amounts (millions)以前漏解析，现按明确问题证据识别，保护百分率、计数、每股及输入单位边界。

## 漏拒的具体原因

反事实Nimbus题的材料没有任何具名发行人，只使用匿名we/our。OQA保留Nimbus约束；OES取到了表中金额，却没有提供将匿名发行人与Nimbus连接的来源证据，仍返回found=true。已有补充提示允许在“没有竞争主体”时用问题具名公司解释匿名报告者，这条规则过宽。

可确认的是主体身份未验证，而不是仅凭Q/D就能证明材料属于另一家公司。审计能从文件名恢复ANET身份，但模型输入没有该信息，不能作为隐藏查询或答案oracle。未来应要求来源先建立主体身份后再做指代映射；这会减少漏拒，也可能增加去掉发行人标题的正常材料的拒答，需要另批验证。

本轮没有根据这10题再调推理代码并重跑同一套题来宣称改进。[实体证据审查](../research/repairs/20261107/r25_fresh_entity_review.md)。
