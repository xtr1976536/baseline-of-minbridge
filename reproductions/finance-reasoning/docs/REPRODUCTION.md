## 必要代码补充和冲突选择

- 作者 `rag_parallel.py` 依赖缺失的 `src.index`、本机绝对目录和不可用缓存，实际答案生成代码被注释；原变量 `judge_useful_functions` 还遮蔽同名函数。改为独立、可直接运行的三阶段流水线，使用本地精确矩阵内积检索，不需要检索服务器和 FAISS 服务。精确检索与完整向量内积排序等价。
- 原检索服务从 `AutoModel` 取 CLS 向量，且没有显式 `.eval()`。Contriever 官方说明要求 mean pooling。论文只说明 Contriever，没有指定 CLS；本实现采用官方掩码平均池化并关闭 dropout，作为明确的实现选择，不声称恢复作者未公开的最终索引。
- 公开函数 `article-1475` 的参数 `1_recovery_rate` 不能编译。函数在本方法中是供检索和 LLM 参考的文本，并非直接执行的标准程序，因此保留原函数字节，仅从 docstring 文本提取描述；没有删掉该候选或修改其数学定义。审计在 `research/library_audit.json`。
- 原筛选解析会在漏标签时静默省略候选。本实现仅接受完整、按序的 30 个 `USEFUL/USELESS` 标签，忽略单纯外层代码围栏；格式错误计本次模型失败，不偷偷变成普通 top-3，不追加纠错调用。
- 原评测使用 `eval`、任取列表首值等宽松转换，与论文对单一数值、单位及符号的严格要求有冲突。本实现直接使用程序返回的单一有限实数或布尔值，不执行字符串表达式，不任选多值结果，不做符号或单位匹配尝试。
- 原 PoT 提示词在 `def solution()` 内结束，因此既接受完整函数，也接受续写函数体。只做围栏移除和必要缩进包装，不修改计算步骤，不根据金标补代码。
- 生成程序在不继承 API 密钥的独立进程内运行，AST 限制文件/网络与动态求值入口、允许有限数学依赖、超时终止。它是受限数学执行器，不能宣称为操作系统级安全沙箱。超出支持范围的代码失败计错，不删题、不让更强模型修复。支持 `math`、`decimal`、`statistics`、`fractions`、`datetime`、`collections`、`numpy`、`numpy_financial`、`sympy` 及 `scipy.optimize/stats/signal` 的明确数学和日期操作；正态分布及日期计算是公开函数库确实使用的依赖。

- 检索序列最长 512 tokens，批量 16，CPU 4 线程；不使用额外向量归一化。函数描述实际截断数和最长长度写入索引 manifest。
- 执行超时 10 秒：沿用作者评测配置。接口并发 2、RPM 30 是保守运行设置，可按用户服务限额调整；所有配置会进入实验指纹。
- 未构造缺失的 few-shot 示例，也未新增系统指令改变原作者提示词。六条模板由固定源文件静态 AST 提取，保留原始文字。

## 公平性、续跑及结果

查询生成器、筛选器和 PoT 使用同一个指定骨干。没有训练、测试集调参、隐式 baseline 或更强 judge。送入模型的 `Problem` 对象只含 ID、问题和上下文；标准解及标签仅用于运行末尾评分。所有 238 个身份和原始哈希在真实模型调用之前固定。

接口调用按实验指纹、问题 ID、阶段、完整消息与参数缓存，断点续跑不重新抽取成功输出。协议或执行错误不自动重试；`--retry-errors` 只恢复接口故障。全部问题和接口故障处理完成后才输出正式 Accuracy；错误回答仍在 238 分母内。预测与缓存均有校验摘要，变更源代码、提示词、依赖、资产或服务设置时拒绝混跑。摘要用于检测误改，不是对恶意篡改的密码学证明。

离线测试和协议替身仅用于程序验证，不能证明 GPT-4o 性能。真实 API 调用和全量实验尚未执行。

2026-11-06 验证结果：41 项测试全部通过；`check` 就绪检查通过；安装包含全部六条原提示词；本地依赖检查通过。真实 3,133 × 768 索引的函数描述最长为 114 tokens，没有任何描述被 512-token 上限截断。年终奖与净现值查询分别召回对应函数，批量 padding 不变性在 float32 的 `1e-5` 容差内通过。238 题均经过三阶段协议替身、独立计算执行和结果保存；续跑新增阶段调用为 0。协议测试目录及其报告明确标为 scripted，不输出性能准确率。
