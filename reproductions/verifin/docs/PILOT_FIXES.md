# 按论文约束修正后的本地小样本验证

本文件记录小样本阶段的过程。随后用户已明确授权并完成修正版 FinanceBench 全量 67 题，见 `runs/financebench-revised-v1/comparison.md`；旧小样本及其版本记录保留。

本轮只修改 VeriFin 主模型路径，并验证固定的 12 道 FinanceBench 诊断题。没有启动新的全量运行，没有运行基线、修复答案、消融或训练。旧 67 题完整结果及原始候选保持不变。

## 代码修正与论文依据

| 论文要求 | 确认的问题 | 修正 |
|---|---|---|
| §3.4：明确问题运算优先 | 将 DPO 内部的“库存变化”误当成整个问题；解析失败后可能回退默认公式 | 从显式算式、角色标签和期间编译定义，支持嵌套平均与变化；明确给出的定义无法解析时弃答，禁止回退到可能冲突的注册表公式 |
| §3.4：多步计算及所需操作数集合 | 三年平均比例变成货币叶子的简单平均；额外平均 PP&E 角色污染年度匹配 | 保留注册表内层比例与外层平均，按问题年份展开角色；只绑定公式使用的变量，平均期间不能冒充单年 |
| §3.5：概念、期间与单位独立确认 | 比例输出单位被用于货币操作数，无关外币干扰币种 | 根据各角色概念及相应无维度事实确定 measure/currency，与 ratio/percent/days 输出分开处理，保留请求的货币规模 |
| §3.5：语义明确且 value-blind | 合计“重组与减值”绑定到较窄的 `RestructuringCharges=0` | 增加 `RestructuringCostsAndAssetImpairmentCharges` 组合概念细分。按标签语义选择，不按候选、金标、金额大小或是否为零选择；反转测试值仍选相同概念 |
| §3.5：symbolic-label 第三阶段 | 注册表 qname 完全不在 filing 中时无法进入标签回退 | 恢复唯一最少 surplus-token 标签回退及少量金融名词单复数规范；保留引文、期间、单位、歧义拒绝与启发式 plausibility 检查 |
| §3.5：精确期间 | 英文季度、上年同季度、累计期间混淆 | 依据 filing 季度身份与结束日期匹配，区分单季度和 YTD；没有可证实期间仍弃答 |
| §3.6：确定性 SMT 编译 | 并发公式比较也创建默认 Z3 context | 授权阶段改用安全 AST 和纯符号运算；Z3 对象仅在受锁保护的求解阶段创建，仍不执行 LLM 程序 |
| 评测单位与问题一致 | 参考 DPO 数值缺少 days 单位而被记作正确性未决 | 从明确的 DPO/DSO/days 问题识别参考单位，前后版本统一计分；原始标签小数位与容差不变 |

组合概念是公开注册表的一项本地、可审查细分，不是声称已恢复论文未发布的 126 项概念。公开资产与第三方骨干身份等差异仍见 `REPRODUCTION.md`。

## 公平性与范围

12 个 ID 在修改前冻结，见 `research/pilot_manifest.json`。它们包含 2 个正常控制题及已知概念误接受、舍入差异、误拒绝、公式、单位、期间和标签问题。这是诊断样本，不是随机泛化样本。

复用旧运行中相同的候选答案及相同的 round-robin top-K 检索文本。planner、公式授权、单位、期间和事实绑定不接收候选；只有最后的 claim parser 接收候选，gold 只在 verifier 完成后进入 scorer。没有重新生成答案、提供 gold evidence 或按候选误差改公式/事实。

保留原始标签及严格显示精度计分，没有放宽容差。DPO 单位修正统一用于前后版本。小样本配置只允许 1–20 个冻结 ID；误用 `run` 命令传入小样本配置会在模型加载/调用之前被拒绝。

开发版本保留 v1、仅计分修正的 v2、捕获控制题回归的 v3、修正该回归后的 v4。诊断集合及候选池从未变更。
