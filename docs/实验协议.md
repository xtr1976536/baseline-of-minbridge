# 主模型复现协议

仅运行 ReAct 与 Logic-LM，不复现其他论文 baseline 或消融。

## ReAct

以官方四个 notebook 为准：HotpotQA、FEVER 各 500 个随机 dev 样本，seed=233；ALFWorld 的 unseen 测试任务；WebShop 500 episodes。作者公开代码底座为 text-davinci-002，论文主模型为 PaLM-540B，两者结果不能混用。

作者 README 公开 GPT-3 参考：HotpotQA EM 30.4%、FEVER EM 54.0%、ALFWorld 成功率 78.4%、WebShop 成功率 35.8%。论文 PaLM 参考分别为 29.4%、62.2%、70.9%、40.0%。必须匹配模型、划分与样本数后再比较。

HotpotQA / FEVER 通过当前 Wikipedia 网页交互，存在页面更新和网络漂移。原 WebShop notebook 硬编码远端服务器，不视为当前仍可用，使用前需探测或部署对应环境。ALFWorld 需要独立下载环境。prepare-only 只提取主模型定义，不代表运行主实验。

## Logic-LM

主实验为论文 Table 2 的无 self-refinement Logic-LM，五数据集 PrOntoQA、ProofWriter、FOLIO、LogicalDeduction、AR-LSAT。GPT-4 参考分别为 83.20、79.66、78.92、87.63、43.04%。原方法在执行失败时回退到 CoT，这是主模型自身流程的一部分；用户不要求单独运行 CoT baseline，但最终精确重现仍需取得这些失败样本的回退答案。当前 solver 重放以固定种子随机回退，必须与论文完整设置区分。

作者公开程序缓存不是新生成结果。PrOntoQA 等可先重放缓存验证求解链。LogicalDeduction 程序缓存 299 条，标准数据 300 条，需报告覆盖缺失。训练、其他 baseline 与额外消融均不运行。

## 结果判定

分开标识：端到端原设置复现、替代底座复现、作者程序重放、仅数据/环境检查。保存逐样本预测、错误、API 原始响应、执行耗时、配置、上游 commit 与输入 SHA256。API 密钥不保存进日志和仓库。结果差异报告百分点，不能将少量样本或纯随机回退得分称为成功复现。
