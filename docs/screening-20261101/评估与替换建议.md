# MinBridge候选复现论文：代码优先筛选（2026-11-01）

审查范围：原PDF的Self-Refine、Self-Consistency，以及其余类别全部8篇，共10篇；ReAct和Logic-LM不在本次复查范围。PDF仅作为候选目录，不将其中描述作为已验证事实。

结论：优先保留Self-Refine、VeriFin、FinanceReasoning的明确知识增强设置、I-CALM、DBA；新增PoT作为低成本金融计算方法。GBFR退出当前优先复现清单并保留诊断代码供追踪；DCRC保持排除；Self-Consistency因未找到完整原作者复现包不作为严格官方代码复现项目，若使用现有作者代码中的CoT-SC须明确标记实现来源。训练类保留When Silence Is Golden作有条件候选，Rewarding Intellectual Humility暂缓，不直接列为可运行项目。

## 证据等级与边界

“公开”指能访问实际源文件，而非只有README或未来开源承诺。检查模型主流程、prompt、数据/构建器、评测器、运行参数以及论文关键机制。代码量不等于完整度；参数或工具名相同不代表语义一致。

本轮主要为克隆/文件树与关键源码静态检查；VeriFin额外完成发布数据的评分重算与哈希产物校验；GBFR采用本地已执行过的核心诊断记录。其他项目没有启动收费API或GPU训练，不能视为全套实验跑通认证。DBA/When Silence的git传输曾失败，已用GitHub API检查文件树并读取关键文件；传输失败不算未公开。

## 替换方案：先满足代码质量，再考虑新旧与数量

### PoT：优先新增

Program of Thoughts Prompting: Disentangling Computation from Reasoning for Numerical Reasoning Tasks，TMLR 2023，https://arxiv.org/abs/2211.12588 ，官方 https://github.com/TIGER-AI-Lab/Program-of-Thoughts 。

实际克隆检查：run_finqa.py、run_finqa_cot.py、ConvFinQA与TAT-QA相关入口、prompt、数据及评分在仓库。FinQA默认非greedy调用n=30、temperature=0.5；greedy为n=1。因此建议先PoT greedy主设置。CoT-SC可以复用这个作者仓库已实现的采样投票，明确它是PoT作者提供的SC基线实现，不是SC原作者官方复现包。旧Codex/OpenAI Completion需换调用层，保留prompt、程序执行、样本与评分。PoT单次与PoT-SC不是同等成本或可互相替代的设置。

它承接GBFR/DCRC的“金融数值+程序执行”比较位置，但不具备图谱约束或训练编译器机制，不能声称技术等价，也不是2026最新SOTA。宁可保留更少且可复现的方法，不为“每类4篇”补入不可运行项目。

### FINDER：近期金融方法备选，尚不优先

EMNLP 2025，https://aclanthology.org/2025.emnlp-main.1577/ ，官方 https://github.com/subhendukhatuya/FINDER_POT_Financial_Numeric_Reasoning 。

实际克隆见Flan/Mistral检索训练代码、动态in-context selection、FinQA/ConvFinQA目标程序生成与评测；README说明可用作者retriever输出直接执行目标模块，数据依赖Google Drive。Drive完整下载与模型checkpoint当前未验收，不能认定端到端都齐全。缓存重放较便宜；重新训练检索器/策略不是低成本。只有补充数据包验收通过后再作为“较新金融方法”补位；只重放缓存不叫完整检索链新复现。

### R-Tuning：训练类备选

NAACL 2024，https://aclanthology.org/2024.naacl-long.394/ ，官方 https://github.com/shizhediao/R-Tuning 。

检查官方树含5数据集拒答训练数据构造与评测脚本；训练依赖LMFlow v0.0.5，原示例open_llama_3b；数据在Google Drive，需补充下载验收。以SFT代替GRPO通常减少rollout负担，这是结构性成本判断，不是实测GPU小时。LoRA/QLoRA或缩小模型如偏离作者设置，应标为适配版本，不能假称原结果复现。比前述训练RL的代码风险可控，但仍不应未经资源验证就称低成本原设置。

## 建议实际清单

立即准备：Self-Refine（GSM设置）、PoT（金融greedy设置）、VeriFin（固定数据指定底座）、FinanceReasoning（明确函数知识增强设置）、I-CALM（PopQA）、DBA（已发布DSL数据设置）。

有条件第二阶段：When Silence Is Golden；R-Tuning作为训练型替代。两者先做数据/代码和显存验收，当前不自动启动GPU训练。

移出/暂缓：GBFR（核心与论文不一致）、DCRC（保持排除）、Self-Consistency独立原设置项目（完整官方包未定位）、Rewarding Intellectual Humility（代码bug及全参RL风险）。SC若作为轻量算法基线可明确采用PoT仓库实现，不应隐瞒来源。

不为凑数量强制替换每一篇。若必须保留2025-2026“近期金融模型”标签，FINDER是待数据验收候选，PoT归入经典可执行推理；不将PoT改写为近期工作。

## 成本衡量，不提供虚假美元或GPU小时

令N为评测样本数、K为采样轨迹数、R为反馈轮数。单次生成近似N次；SC近似NK条完成；Self-Refine GSM近似N(1+R)次、其他任务可能N(1+2R)次；DBA需N乘Direct/Assistive/Incremental各自调用总数，再加判断；RAG需检索、生成及可选过滤/抽取。相同调用数也会因长上下文、思考token、缓存和模型单价不同而价格差异很大。

纯示意：1000样本、每完成输入4000/输出1000 token，一次生成约4M输入+1M输出；K=30约120M输入+30M输出（缓存、批处理、不同轨迹长度未计）。实际费用应先20题测usage，再用所选服务实际计价；本轮不调用收费模型。

全原论文多模型、多数据集主表与“一个主方法的指定底座主实验”不同。后者可低成本建立方法可运行性，不能称已恢复整篇主表。训练类尤其不能把0.5B试跑或LoRA适配当作原1.5B全参SFT+RL结果。
