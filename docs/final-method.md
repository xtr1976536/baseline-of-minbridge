# 最终方法与证据边界

主线沿用论文：自然语言→模型生成符号程序→作者符号求解器→答案映射；失败按同ID采用CoT。对比Table 2无self-refinement的GPT-4设置。固定消息、原始模板、数据、作者求解器和评价程序，替换服务商声明的gpt-5.6-sol。作者数据文件名为dev.json，但这是作者公开CLI使用的评测文件。

新增部分全部披露：

1. 通用程序的26词格式约束；CSP/Z3分别使用configs中固定短格式约束。原示例不修正，原字符串仍是请求完整后缀。
2. 仅LogicalDeduction做两项表面适配：单个程序的同行/重复同行标题整理；Query的(A)转A)。不选多程序、不改表达式。新增适配样本逐条记录原文、规范化程序与编辑次数。
3. 仅LogicalDeduction的CoT在Markdown清理后采用显式唯一选项提取（作者固定分隔短语优先），冲突/无标记/越界时弃权。其余数据集继续原清理规则。原始分数保留。
4. 运行时Prover9路径配置和AR-LSAT子进程Z3弃用警告过滤；不改作者约束转换器、Pyke关系查询或判定逻辑。映射/运行异常明确记录并回退，属于作者可能直接崩溃时的健壮性扩展。
5. 并发生成、原子记录、显式续跑、fingerprint和请求/响应校验；不做失败程序语义修正重试。

## LogicalDeduction的批次区分

原低可执行率300题只是诊断，不再作为当前主结果。修正后300题新生成为main源：295可执行、293个求解答案正确，原提取只识别2个正确回退，得到295/300。后来新增显式CoT提取后，对**原配套**CoT重新读取识别了全部5个正确回退，因此当前代码主分数298/300。原运行和新重评的逐题记录分开保存。

独立CoT是另一批新生成300条，295条正确；不是把它混入main使分数升高。其原Markdown-only分数152/300。全部失败/弃权仍记错，没有为了追分改提取边界。

## 统计与协议局限

替代底座、格式约束、显式提取、预算执行不可认证等意味着结果不是底座外完全零差异复现。高于论文不是因果证明。小样本曾用于格式开发，之后完整官方评测包含这些题；应披露这种适配过程。AR-LSAT实际公开数据231，而部分作者材料写230；不删题凑数。

FOLIO本地证明的资源限制使超时状态可能变化。本次清理时的离线复验中，一条原timeout转为可执行但答错，总准确率156/204不变，Exe_Rate从158/204到159/204，Exe_Acc从126/158到126/159。发布主表保留冻结的原完成成绩，复验文件附在同目录，避免挑更有利状态。

全部最终运行3970条请求的对应关系核验见reports/final-integrity.json；原始程序、原始CoT、响应usage、原始prompt、实际请求参数、断点日志以gzip保存在experiments/final。只删除被替代的当前代码/成绩文件，没有抹除Git历史或本机原始实验。
