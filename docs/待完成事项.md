## 本轮实际适配

- 不安装作者包含 CUDA/Linux 无关依赖的全量 requirements，使用独立最小依赖与完整冻结锁。
- Prover9 在 macOS 原生编译，记录编译命令和日志；Linux 原二进制通过子模块保留。
- Pyke 每题清除它自身生成的 compiled_krb 缓存，避免 Python 3 的 namespace 包产生空 __file__；不修改题目或推理规则。
- 固定随机回退种子，仅用于非端到端求解器诊断；完整主表用 CoT 回退。
- Notebook AST 导出只排除顶层评测循环和 API key 赋值，保留作者 ReAct 核心函数。Completion/Chat 接口区别记录于结果。
